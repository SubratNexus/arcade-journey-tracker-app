# Festival poster schedule (v6.3)

Dates use the New Delhi / IST panchang (Drik Panchang, AstroSage). Outside India some years fall one day earlier (2027, 2030, 2031, 2034, 2035), but the 5-days-before window still covers it.
Confidence: High = several panchang sources agree. Medium = fewer sources checked; lunar-calendar dates can move by 1 day, so re-verify when the year is near.

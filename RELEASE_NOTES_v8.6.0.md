# Arcade Journey Tracker v8.6.0 — built-in build 816

## Personal Arcade Agent

- Replaces the inactive planner placeholder with an in-app Personal Arcade Agent.
- Builds a plan from the current calculator total, tier, target tier, badge counts, unfinished active Skill checklist, weekly hours and preferred focus.
- Uses the public `agent-data/public-feed.json` generated by `SubratNexus/arcade-intelligence-2.0` through the new Netlify Function.
- Shows the programme feed's generation time, event count, reviewed count, pending-review count and relevant YouTube metadata count.
- Does not automatically classify pending announcements as actionable. Unreviewed official-source candidates remain leads until approved.
- Uses deterministic rule-based output only. It does not call an external AI model or send the visitor's profile to a third-party model provider. The request excludes profile URL, display name, email and Google login details.

## Intelligence API

- Adds `/api/intelligence` with health, public-feed, planner and authenticated owner-digest actions.
- Reads only the fixed HTTPS public-feed URL for the GitHub agent repository, with schema validation, response-size cap, timeout, 5-minute in-memory cache and last-good-cache fallback.
- Filters and bounds public source URLs and event fields before returning data to the browser.
- Limits planner requests per IP and bounds request-body size and profile fields.
- Keeps external AI disabled. This is a deliberate terms-and-audience safeguard: current Gemini API terms require API users to be 18+ and do not allow API clients likely to be accessed by under-18s.

## Owner email digest

- Adds an authenticated Developer Mode action to send a digest to the configured owner inbox.
- Requires exact trusted Google Staff group evidence plus `officially_announced`, `human_review_required: false` and `notification_approved: true`.
- Uses Resend with an idempotency key and Netlify Blobs state to avoid repeat delivery.
- Fails closed if Netlify Blobs cannot be read or written; no digest is sent for pending/unreviewed announcements.
- Reuses `RESEND_API_KEY`, `OWNER_EMAIL` and optional `MAIL_FROM` already used by the release-approval workflow.

## Existing features retained

The v8.5.0 calculator, saved profile behaviour, manual point corrections, Facilitator settings, seasonal artwork, light/dark layout, public catalogue connection, Community panel, Hot Update Manager and existing Netlify Functions are retained. A complete deployment is required because this release adds a Function and an API route.
